# Anuska Dutta — Portfolio

A single-page portfolio site, styled as a support-ticket / CRM dashboard.

## Files
- `index.html` — the portfolio page
- `resume.pdf` — downloadable resume, linked from the page

## Host on GitHub Pages
1. Create a new repository, e.g. `anuska-portfolio`.
2. Upload both `index.html` and `resume.pdf` to the **root** of the repo (keep them in the same folder — the page links to the resume as `resume.pdf`).
3. Go to **Settings → Pages**.
4. Under "Build and deployment," set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
5. Save. Your site will be live at:
   `https://<your-username>.github.io/anuska-portfolio/`

## Updating the resume
Replace `resume.pdf` with a new file of the same name, or update the `href="resume.pdf"` links in `index.html` if you rename it.
